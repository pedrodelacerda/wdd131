Site Plan

Site Name: Voxel Forge 3D

This name represents in a different way, the purpose of the site, to create in 3d, a project needed by the client visiting the site. The name is a combination of "Voxel", which is a term used in 3D modeling to represent a volumetric pixel, and "Forge", which implies the act of creating or shaping something. Together, "Voxel Forge 3D" suggests a platform or service that allows users to create and shape 3D models using voxels, making it an ideal name for a site focused on 3D modeling and design.

Site Purpose

The purpose of the site is to provide a platform for user to request a service of 3D printing, where they can submit their project ideas and have them transformed into tangible 3D models. Also the site will offer a catalog of pre-designed 3D models that users can browse and purchase, as well as a contact section for inquiries and support.

Scenarios

  1. What type of 3D models are available in the catalog? Also, how can a user request a quote for a custom 3D geek printing project?
  2. Does the site offer technical and heat-resistant materials for engineering applications, and how can users submit the STL files for custom projects?

Color Scheme

  • Primary Background (#0B0F17): Deep dark blue-gray used for the overall site background (<body>) to set a modern dark mode.
  • Secondary Background (#1A202C): Industrial dark gray for structural elements like the <header>, <footer>, navigation panels, and product cards.
  • Primary Accent (#00D2FF): Vibrant neon cyan used exclusively for interactive elements like buttons, links, and active menu states.
  • Borders and Dividers (#4A5568): Metallic gray designed for subtle structural outlines, perfect for <fieldset> borders and dividers.
  • Primary Text (#E2E8F0): Soft high-contrast off-white applied to all headings (<h1>, <h2>, <h3>) and main paragraphs for high legibility.
  • Secondary Text (#A0AEC0): Muted gray for low-hierarchy text, such as placeholders, image captions, and footer copyright notes.

Typography

  • Primary Headings (Orbitron / Rajdhani): A sharp, geometric tech font used for main titles to match the futuristic look of the voxel logo.
  • Body Text (Roboto / Segoe UI): A clean, highly legible sans-serif font used for paragraphs and navigation links to ensure a comfortable reading experience.
  • Technical Text (Roboto Mono / Consolas): A monospace font used for labels, numbers, product specifications, or code-like elements to reinforce the engineering theme.

Wireframe

  • Mobile Layout (1 Column): All content is stacked vertically in a single column; the header displays the logo and a simplified menu icon, followed by the main title, stacked institutional text blocks, and a vertical image gallery.
  • Desktop Layout (Multicolumn): The header expands horizontally with the full link menu on the right; the main hero section splits in two (text on the left, primary image on the right), and the three informational blocks are aligned side-by-side in three parallel columns.
  • Visual Elements (Placeholders): The diagrams use purely basic geometric shapes (gray boxes with thin borders) and structural text labels ([Logo], [H1 Title], [Image Area]) to demonstrate page hierarchy and responsive behavior without visual clutter.
